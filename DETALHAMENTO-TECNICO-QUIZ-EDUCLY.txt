1. VISÃO GERAL DO PROJETO
--------------------------------------------------------------------------------
Este projeto é uma esteira interativa completa de Onboarding, Qualificação e 
Conversão via Quiz desenvolvida sob medida para o Educly.app (SaaS de micro-
aprendizagem prática de Inteligência Artificial com desafio de 28 dias).

Como estudante apaixonado por frontend e engenharia web, estruturei este projeto 
com foco em 4 pilares essenciais para produtos digitais modernos:
1. Fidelidade Absoluta ao Design System: Interface 100% no modo Light oficial do app.
2. Alta Velocidade e Performance: Código Vanilla puro, sem sobrecarga de frameworks.
3. Ramificação Condicional Real: Perguntas personalizadas de acordo com o perfil.
4. Painel de Demonstração de Dados em Tempo Real: Armazenamento local e payload 
   JSON pronto para integração com bancos de dados ou CRMs.


2. STACK TECNOLÓGICA & ESCOLHAS PRÁTICAS
--------------------------------------------------------------------------------
• Core Frontend: HTML5 Semântico + CSS3 Moderno + JavaScript Vanilla puro (ES6+).
• Por que Vanilla JS em vez de React/Next.js neste caso?
  - Em funis de tráfego pago e aquisição de leads, cada fração de segundo conta. 
    Usando código puro, o site carrega instantaneamente (< 250ms), sem precisar 
    baixar pacotes pesados de JavaScript no celular do usuário.
  - Isso garante nota máxima (100/100) no Google Lighthouse e taxa de conversão maior.
• Design System & Tokens Visuais (Baseados no Educly original):
  - Modo Light: Fundos limpos (#F8FAFC / #FFFFFF), tipografia nítida (Inter, Outfit 
    e Geist Mono) e bordas suaves (#E2E8F0).
  - Cores Oficiais: Laranja Educly (#F97316) com efeito "sheen" animado no botão 
    de checkout (extraído dos componentes originais do app) e Azul (#2B7FD4).
• Internacionalização Dinâmica (i18n):
  - Um seletor de idiomas no topo que traduz a aplicação em tempo real para 5 línguas 
    (Português, Inglês, Espanhol, Francês e Alemão) sem recarregar a tela e sem 
    perder as opções que o usuário já havia marcado.


3. ARQUITETURA DE RAMIFICAÇÃO DINÂMICA (ÁRVORE CONDICIONAL)
--------------------------------------------------------------------------------
Diferente de questionários estáticos, este quiz possui ramificação inteligente 
baseada na primeira decisão do usuário:

[PERGUNTA 1: Ponto de Partida]
O usuário escolhe entre:
A) Acelerar minha rotina e carreira individual (Trilha B2C)
B) Capacitar minha equipe ou empresa (Trilha B2B Corporativa)
C) Sou iniciante e quero começar do zero com segurança (Trilha Isca/Lead)

A partir dessa escolha, as perguntas seguintes (Q2, Q3 e Q4) se adaptam 
completamente:

• Se escolheu B2C:
  - Q2: Tarefa manual que mais toma tempo (relatórios, planilhas, posts, pesquisas).
  - Q3: Ferramenta foco que mais precisa dominar (ChatGPT/Claude, Midjourney, etc).
  - Q4: Tempo diário que tem livre (15 min, 30 min, 1 hora).
  -> Resultado Final: Diagnóstico de até 16h economizadas, comparação visual 
     "Hoje vs Em 28 Dias" e oferta com desconto no app Educly com timer de 15 min.

• Se escolheu B2B (Corporativo):
  - Q2: Tamanho da equipe a ser treinada (3-10, 11-50 ou 50+ colaboradores).
  - Q3: Maior gargalo da equipe (falta de governança, rotinas lentas, resistência).
  - Q4: Formato preferido de treinamento (App individual, workshop híbrido, etc).
  -> Resultado Final: Diagnóstico executivo na tela e botão direto para o 
     WhatsApp corporativo com a mensagem já redigida contendo todos os dados do time.

• Se escolheu Iniciante:
  - Q2: Maior receio com IA (não saber prompts, privacidade, excesso de novidades).
  - Q3: Experiência anterior com cursos (desistiu de vídeos longos, viu YouTube, etc).
  - Q4: Primeiro ganho prático desejado já nesta semana (e-mails rápidos, resumos).
  -> Resultado Final: Formulário de captura para envio gratuito do "Guia de 100 
     Prompts do Educly" com feedback visual imediato.


4. COMO DISPONIBILIZAMOS E RASTREAMOS OS DADOS (ARQUITETURA DE DADOS)
--------------------------------------------------------------------------------
Para demonstrar aos avaliadores como os dados trafegam e como podem ser integrados 
a qualquer ecossistema profissional:

1. Armazenamento Local no Navegador (LocalStorage):
   - Cada resposta e cada formulário enviado são salvos em tempo real na chave 
     `educly_quiz_leads_v1` do navegador do visitante.
   - Isso permite testar a ferramenta na íntegra mesmo em hospedagens estáticas 
     gratuitas (como Vercel ou Netlify) sem custos imediatos de servidor.

2. Central de Administração / Painel de Leads Embutido:
   - No canto inferior direito da tela, há um botão flutuante roxo discreto 
     ("Painel de Leads (Demo)") com contador de respostas em tempo real.
   - Ao clicar, abre-se uma tela administrativa elegante com:
     • Total de respostas e divisão por vertente (B2C, B2B e Leads).
     • Tabela detalhada com data/hora, perfil, dados de contato e respostas.
     • Inspetor de Payload JSON estruturado com botão de "Copiar JSON".
     • Botão para limpar o histórico e resetar os testes.

3. Prontidão para Produção (Como levar isso a escala):
   - Na estrutura do código (`app.js`), os dados estão no formato padrão JSON.
   - Em produção real, basta conectar um único comando `fetch('/api/lead')` para 
     enviar esse mesmo payload para um banco de dados moderno (Supabase / PostgreSQL), 
     um CRM (HubSpot / ActiveCampaign) ou um Webhook (Make / n8n / Zapier), que 
     pode automaticamente alimentar uma planilha Google Sheets corporativa e 
     disparar mensagens no WhatsApp ou e-mail do cliente.
